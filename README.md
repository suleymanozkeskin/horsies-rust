# horsies-rust moved

The Rust crates of Horsies moved to the Horsies repository:
**https://github.com/suleymanozkeskin/horsies**

- Code: the crates are under `crates/` in that repository. `horsies` is in
  `crates/horsies`, and `horsies-macros` is in `crates/horsies-macros`.
- crates.io: the crate names are unchanged: [`horsies`](https://crates.io/crates/horsies) and
  [`horsies-macros`](https://crates.io/crates/horsies-macros).
- Docs: https://suleymanozkeskin.github.io/horsies/rust/. The old docs
  address redirects there.
- Issues and pull requests: open them in the Horsies repository. The open
  issues of this repository moved there.
- History: the Horsies repository holds the full history of this repository.
  Commit ids changed in the move. `rust/imported-commit-map.txt` in the Horsies
  repository maps each old commit id to its new id. Each published crate
  version has a `rust-v<version>` tag there.

This repository keeps its original history, closed issues and pull requests.
It gets no new changes.
